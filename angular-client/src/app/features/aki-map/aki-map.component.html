AKI 分期是怎麼算出來的

資料來源

以上傳的兩份 Excel（留院病人清單 ＋ CKD-AKI 病患明細）為準，用病歷號串接，彙整每位病人的肌酸酐（Cr）數值——含門診、急診、住院三個來源、去重後依日期排序。

baseline（基準值）怎麼取

  • 優先採門診（OPD）最低值當基準，代表入院前的真實基礎腎功能。
  • 沒有門診值時，取「時序上較早的前值最低」為基準——只跟更早的數值比，尊重時間方向，避免把正在恢復的病人誤判成新發 AKI。

KDIGO 分期（僅用 Cr）

  • Stage 1：Cr 升到 baseline 的 1.5–1.9 倍，或 48 小時內上升 ≥ 0.3 mg/dL
  • Stage 2：Cr 升到 baseline 的 2.0–2.9 倍
  • Stage 3：Cr 升到 ≥ 3.0 倍；或 Cr ≥ 4.0 mg/dL 且伴隨急性上升；或已開始透析
  • 取整段病程中最高的分期為結論

特別歸類

  • 疑似 ESRD／慢性：全段最低 Cr ≥ 4.0 → 視為慢性腎衰，不計為 AKI
  • 單筆無法判定：只有一筆 Cr，無前值可比對
  • 無 Cr 資料：該病人在區間內沒有肌酸酐數值

限制

  • 只用肌酸酐、沒有納入尿量，會低估尿量型（oliguric）AKI。
  • 抽血日期較稀疏時，48 小時／7 天的時間窗以「窗內」近似處理。
