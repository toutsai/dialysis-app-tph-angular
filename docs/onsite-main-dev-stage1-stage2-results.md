- 六個非庫存 Excel 上傳入口改用背景解析；一個解析工作與最多兩個等待工作，忙碌、逾時或解析服務中斷會回應可重試錯誤。資料庫寫入仍在原交易中。
- 護理月／週表保留穩定的日期與護理師識別，減少重複建立表格項目，班別原地修改仍會反映。
